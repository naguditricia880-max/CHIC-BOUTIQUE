# CHIC-BOUTIQUE
A Java-based business till system for Chic Boutique.
## Features
- Displays available items and prices
- Calculates item subtotals
- Applies discount rules
- Calculates the grand total
- Generates an itemised receipt

## Items
- Shirt — UGX 25,000
- Trousers — UGX 40,000
- Shoes — UGX 60,000
- Dress — UGX 55,000

## Technologies
- Java

## Concepts Used
- Variables and data types
- Arrays
- Operators
- Conditional statements
- Loops
- Methods

## Project Status
Currently implemented using procedural programming. The project will be extended with object-oriented programming concepts throughout the course.
